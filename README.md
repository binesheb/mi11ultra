# Mi 11 Ultra Flash Tool

A small Windows utility for working with Xiaomi Mi 11 Ultra devices using ADB and Fastboot.

## Goal

Make common Mi 11 Ultra flashing and recovery tasks easier without requiring users to manually type every ADB/Fastboot command.

## Status

Early development. Features will be added incrementally and each change will remain small and focused.

## Safety

Flashing firmware can erase data or make a device unbootable. Always verify the device, firmware files, and required unlock state before flashing.
